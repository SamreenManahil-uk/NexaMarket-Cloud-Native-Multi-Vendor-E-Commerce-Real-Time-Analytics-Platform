# NexaMarket-Cloud-Native-Multi-Vendor-E-Commerce-Real-Time-Analytics-Platform
Cloud-native multi-vendor e-commerce and real-time analytics platform featuring Vue 3, TypeScript, Node.js, Express, PostgreSQL, Kafka, PySpark, Airflow, Data Science, Power BI, JWT/RBAC and an AI-powered catalogue assistant.
NexaMarket is an end-to-end multi-vendor e-commerce and analytics platform designed to demonstrate modern full-stack engineering, event-driven architecture, data engineering, data science, business intelligence and AI integration in a single portfolio project.
The platform provides customer commerce experiences alongside dedicated Seller and Admin dashboards, secure authentication and role-based access control, inventory and order management, a catalogue-grounded AI shopping assistant, Kafka-based event infrastructure, Spark Bronze/Silver/Gold analytics pipelines, RFM customer analysis, K-Means segmentation, demand forecasting and interactive analytics through both the web application and Microsoft Power BI.
